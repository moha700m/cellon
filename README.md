# سيلون

محاكي نواة خلية أصلي في المتصفح. مفسّر PowerPC من نمط المستخدم (٣٢ بت، بايت كبير)، مجمّع، ذاكرة، نداءات رسم تُنزَّل إلى طابور RSX مبسّط، ومؤشرات لستة SPE.

ليس تابعًا لسوني، ولا يحتوي فيرمويرًا، ولا يشغّل أقراص المتاجر. محاكاة البلايستيشن ٣ التجارية مشروع آخر (RPCS3) ولم تُنسخ شفرته هنا.

البرامج الثلاثة — جدار النور، ثعبان الخلية، مدار — منطقها تعليمات تُنفَّذ على النواة، لا سكربت اللعبة.

## عقد النداء

`sc` و`r0` رقم النداء:

| r0 | الوظيفة |
| --- | --- |
| 0 | خروج، الرمز في r3 |
| 1 | انتظار الإطار، ويعود قناع الأزرار في r3 |
| 2 | مسح الإطار بلون r3 |
| 3 | مستطيل: r3 x، r4 y، r5 عرض، r6 ارتفاع، r7 لون |
| 4 | رقم: r3 x، r4 y، r5 القيمة، r6 لون |
| 5 | عدد عشوائي في r3 |
| 6 | حمل SPE: r3 الفهرس، r4 النسبة |
| 7 | نغمة قصيرة، التردد في r3 |

السجل r31 محجوز للمجمّع. نقطة الدخول وسم `start`.

الأزرار: يسار 1، يمين 2، أعلى 4، أسفل 8، إكس 16، دائرة 32، مربع 64، مثلث 128، ابدأ 256.
